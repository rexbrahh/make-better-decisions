# Scoped review acceptance

Date: 2026-10-12. Scope: v1.1.0 source and installation acceptance. The user authorized publication and Codex installation.

## Local checks

1. Run the full unit suite, including parser, receipt, contract, failure, and launcher regressions.
2. Run native macOS isolation checks with their required sandbox permission.
3. Run bounded real-Jev legitimate-work and adversarial cases. Record each actual verdict and API count.
4. Replay fixed SDK and web transcript prefixes. Compare timings, retained evidence size, and hashes.
5. Review the whole working-tree change with an independent reviewer. Fix material findings with causal regressions.

## Release checks

1. Preview the installation plan with the chosen review mode and installed plugin root.
2. Back up host configuration before operator-authorized application.
3. Verify native hook counts and parent/worker inheritance in a fresh live chat.
4. Exercise required outages and explicit availability recovery in that installation.
5. Verify configured stdio wrappers and record unsupported GUI, HTTP-service, and Linux boundaries.

## Acceptance boundaries

Signed receipts establish completed review and scope. They do not establish code correctness. Source inspection, executable checks, and independent review remain necessary.

History supplies architectural context. It cannot authorize fresh-chat writes. User quotations establish the user's words. Printed tool assertions and parent briefs remain observations.

The boundary helper and selected host isolation profile are required for tamper protection. Same-UID privileged processes, operators, and trusted external services remain outside that boundary. Local fixture tests do not establish live activation.
