| Issue | Correction | Evidence |
| --- | --- | --- |
| The timeout test restored its shared HTTP transport while its worker still ran | Join the fake response-body reader before transport cleanup | The race detector reproduced the conflict. The corrected race run passes. |

## Acceptance commands

Use `GOCACHE="$TMPDIR/go-build"` and `GOTOOLCHAIN=local` for Go commands.
The oracle commands also require `AGENT_DECISIONS_PYTHON=/opt/homebrew/bin/python3` and `AGENT_DECISIONS_PYTHON_SOURCE` pointing to `python-final`.

| Check | Command |
| --- | --- |
| Ordinary suite | `go test -p 1 -count=1 ./...` |
| Complete oracle | Both oracle environment variables, then `go test -p 1 -count=1 ./...` |
| Real replay | Oracle variables and `AGENT_DECISIONS_REAL_TRANSCRIPTS=1 go test -count=1 -v -timeout 10m -run TestReplayRealTranscripts ./internal/hook` |
| Race | `go test -race -p 1 -count=1 -skip '^TestLargeDiscardedToolOutputsDoNotDominateContextBuilding$' ./...` |
