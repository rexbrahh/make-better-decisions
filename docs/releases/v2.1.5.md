# Skip blank installer diagnostics

Installer timeouts now skip blank stderr lines before selecting the first useful diagnostic.
Previously, a leading newline produced an empty diagnostic even when the next line explained the failure.

The shared helper uses its existing whitespace check before redaction and clipping.
Credentials remain redacted. Diagnostic length and process deadlines remain unchanged.
The queue regression and both child-process timeout regressions fail before the repair and pass afterward.
