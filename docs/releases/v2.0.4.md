# Bound blocked RPC request writes

## Outcome

A Codex child that stops reading stdin cannot block request submission beyond the configured RPC deadline.
The existing bounded child cleanup runs after expiry.

## Change classes

Request submission and response reading share one absolute deadline.
Pipe deadline expiry reports the existing `InstallError` timeout.
Request encoding, explicit socket selection and initialization-only recovery remain unchanged.

## Evidence

The regression's fake child accepts initialization and stops reading a one-megabyte request.
Before the correction, a 0.25-second budget waits 2.01 seconds and reports `Broken pipe`.
After the correction, the complete installer package passes, including the recovery and no-replay controls.
See the [measured candidate](../validation/rpc-write-deadline-2026-10-15.md).

## Verification

Unit suite, complete Python oracle, live Jev gates, vet and diff checks pass.
Both release assets match their SHA-256 pins.

## Upgrade

Update both native plugins and run their protected installers. Trust the changed Codex hooks.

## Residual risk

Child termination has its own existing bounded cleanup period.
GUI operation and live worker inheritance remain unverified.
