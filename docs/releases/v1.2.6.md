# v1.2.6

## Outcome

The private-state guard denies glob and shell spellings of the state path, such as `cat ~/.local/state/agent-d*/ledger.key`. Before this release, these commands passed the guard. An agent could then read the ledger key in a command that ran outside the host sandbox.

Hook input and transcript lines with bad UTF-8 or a lone surrogate no longer cause a hook error. The guard and the input parser now give the same result on every Python version. This prepares the Go rewrite, which must match the Python behaviour exactly.

## Change classes

- Compare a glob path with the state directory one component at a time. A `**` component matches any number of directories. Deny the path when its components can match the state directory or a path below it.
- Expand `~`, `$HOME`, `${HOME}`, and comma braces in each shell word before the check.
- Allow a glob that ends above the state directory, such as `ls ~/*`, as a literal parent directory is allowed.
- Expand `~user` with `os.path.expanduser`, which keeps an unknown user as literal text. `Path.expanduser` raised `RuntimeError`.
- Read hook input and transcript lines as UTF-8 with replacement characters. Replace each lone surrogate escape with U+FFFD.
- Remove the Python 3.9 `re.error` branch. An invalid bracket range compares as literal text.

## Evidence

- On 2026-10-14, v1.2.5 allowed these commands under Python 3.9.6 and 3.15: `cat ~/.local/state/agent-d*/ledger.key`, `cat ~/.local/state/*/ledger.key`, `cat ~/.local/sta?e/agent-decisions/ledger.key`, `cd ~ && cat .local/state/agent-decisions/ledger.key`, `cat $HOME/.local/state/agent-decisions/ledger.key`, and `cat ~/.local/state/agent-{decisions,x}/ledger.key`.
- The v1.2.5 guard used the whole tool path as an `fnmatch` pattern. Thus, a glob matched only when it named the state directory itself. Because `*` also matched `/`, the guard also denied `ls ~/*` and `/*`.
- The Claude Code sandbox and the Codex filesystem policy deny the state directory. Thus, the guard is the second layer. It is the only layer for a command that runs outside the sandbox.
- `Transcript.turn_key` raised `UnicodeEncodeError` on a lone surrogate. The hook then denied every reviewed call in that turn.
- `ls ~nosuchuser/x` and `file_path: "~nosuchuser/x"` raised `RuntimeError` in v1.2.5, and the hook denied the call.
- The owner chose these rules: "Fix in Python first", "Approve all three", and "Expand $HOME, ~ and {a,b}". Jev picked component matching that allows ancestor globs (ADVISORY, `review_5d96d982`). Jev also picked pattern-only matching below the state directory (ADVISORY, `review_9e9b2cdc`).
- On 2026-10-14, Jev accepted quotes of two messages that the owner typed during a running turn, and of one selected question-box answer. Thus, Claude Code runs `UserPromptSubmit` for queued messages, and both v1.2.5 captures work. This closes the first residual risk of v1.2.5.

## Verification

Five new regressions cover the glob and shell spellings, ancestor globs, unknown `~user` words, transcript surrogates, and hook input bytes. All five fail on v1.2.5 and pass on v1.2.6. All 385 tests pass under macOS system Python 3.9.6 and Homebrew Python 3.15, outside the Claude Code Seatbelt sandbox.

A scan compared the v1.2.5 and v1.2.6 guards on 93,286 tool calls from local Claude and Codex transcripts. Each call used its recorded working directory.

- 4 calls became allowed. Each one used a glob that ends above the state directory: `~/.local/*`, `/Users/rexliu/*/`, `/*`, and `/*.*?*/`.
- 8 calls became denied. Each one was a Python heredoc with a recursive glob, such as `*/**/summary.json`, that the guard resolved from the home directory. These are false denials.
- No call raised an error. Parsed user text did not change in any transcript.

## Residual risk

- The guard does not find a path that a program computes at run time, or a path in a variable other than `HOME`. The host sandbox remains the boundary for those paths.
- A recursive glob that can reach below the state directory is denied, even when no such file exists. The agent receives a clear error.
- The guard checks only the first 64 brace expansions of a shell word.
- A v1.2.5 ledger row that contains a lone surrogate no longer matches the replaced transcript text. Such rows expire after 14 days.
- Activation changes the checks of every running agent at its next tool call, because the hooks read the current runtime on each call.
