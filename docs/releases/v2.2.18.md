# v2.2.18 — Snap option references

Snap decision questions now refer explicitly to each operation in shared `state.options`.
The full descriptions remain in that state and in the choice criteria.
The question identifiers, invariant text, answer criteria and review thresholds remain unchanged.
Jev retains its existing question bytes and API code.

This change removes repeated long descriptions from the pattern, instruction and invariant checks.
In the measured synthetic fixture, two descriptions total 4,964 bytes and seven invariants produce 32 questions.
The two client requests shrink from 82,444 to 38,893 bytes, a 52.8% reduction.
The shared state remains 6,287 bytes. This measurement is not a token count or a capacity guarantee.

Snap's context profile advances from `snap-2` to `snap-3`.
Earlier cached approvals and completed or inherited receipts require a fresh review.
The provider selection, required review mode and existing session exceptions remain unchanged.
