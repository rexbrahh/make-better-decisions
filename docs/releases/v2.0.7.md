# Find Codex outside Homebrew

## Outcome

Default Codex installation works on hosts where `codex` is available on PATH and the Homebrew launcher is absent.
Macs with the preferred executable keep using it.

## Change classes

The CLI parser and default plan writer share executable selection.
Explicit executable and socket overrides retain their behavior.
RPC deadlines, initialization recovery and operation-no-replay rules remain unchanged.

## Evidence

The Linux regression fails both parser selection and plan application before the fix.
The complete installer package passes on macOS and Ubuntu after the correction.
The Linux fixture serves both RPC requests through PATH; explicit overrides pass on both platforms.
See the [cross-platform measurements](../validation/codex-path-2026-10-15.md).

## Verification

Unit suite, complete Python oracle, live Jev gates, vet and diff checks pass.
Both release assets match their SHA-256 pins.

## Upgrade

Update both native plugins and run their protected installers. Trust the changed Codex hooks.

## Residual risk

Hosts must provide the preferred launcher or a working `codex` executable on PATH.
GUI operation and live worker inheritance remain unverified.
