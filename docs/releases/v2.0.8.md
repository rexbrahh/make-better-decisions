# Preserve text during URL sanitization

## Outcome

Sanitization preserves literal marker text and nonsecret URL query values while it redacts credentials.

## Change classes

URL extraction skips numeric markers that occur in the original input.
One `strings.NewReplacer` pass restores URLs without rescanning replacement text.
URL validation, secret-query redaction, CLI redaction and environment redaction remain in place.

## Evidence

Three regressions reproduce literal-marker replacement and decoded-marker corruption before the fix.
All three pass afterward, together with the complete installer package and its Python oracle.
The owner selected this exact numeric-marker correction.

## Verification

Unit suite, complete Python oracle, live Jev gates, vet and diff checks pass.
Both release assets match their SHA-256 pins.
