# v2.0.1

## Outcome

CLI help and diagnostics use plain text without terminal-width wrapping or choice suggestions.
Failed cross-platform builds preserve the previous local release assets and checksums.
The Linux binary includes the `EHWPOISON` error-text correction from the post-switch QA work.

## Change classes

- Production: Linux errno 133 reports the glibc text, `Memory page has hardware error`.
- CLI presentation: remove copied colour, wrapping and suggestion code. Keep argument semantics, required flags, choices, abbreviations and exit statuses.
- Release workflow: build both targets in temporary storage before replacing completed outputs. Keep `dist/` present during compilation.
- QA: correct timeout-test cleanup, replay path substitution, macOS fixture environment and a native-stack oracle assumption.

Recursion algorithms and their existing overflow boundaries remain unchanged.
Canonical JSON encoding, ledger HMAC, gate fingerprints, input hashes and user-key generation remain unchanged.

## Evidence

- All 22 tested packages pass. The complete Python oracle passes, with normalization limited to the retired CLI presentation.
- Real replay passes 2,868 calls from 44 transcripts with zero differences in hook results, Jev requests and ledger data.
- Live Jev passes 86 cases with 82 API calls. Three real headless Claude scenarios pass.
- Linux amd64 passes the full suite and four bubblewrap runtime checks in a privileged Ubuntu 24.04 container.
- The build-failure regression fails before the correction and passes afterward. Repeated normal builds produce matching assets and pins.

After publication, the installed plugin passes fresh Codex read-only and reviewed-patch scenarios.
The installed Claude plugin passes fresh exact-edit, reviewed-design and read-only scenarios.
See the [Mac activation receipt](../validation/v2.0.1-activation-2026-10-15.md).

See the [QA report](../validation/go-qa-2026-10-15.md) for commands, source boundaries and limitations.

## Verification

The race run passes with the fixed-wall-clock performance test excluded from instrumentation.
That unchanged performance test passes in the ordinary suite.
Format, vet, shell syntax and diff checks pass.

The release build uses Go 1.27.2 with `CGO_ENABLED=0` and the existing reproducible-build flags.
Both assets report version 2.0.1. Their SHA-256 values are in `bin/agent-decisions.sha256`.

## Upgrade

1. Update the plugin in Claude Code and Codex.
2. Run `bin/agent-decisions-install --apply` from the updated installed plugin root.
3. Trust the changed hooks in Codex.
4. Restart running agents when convenient, then check the installed version and loaded hooks.

## Residual risk

- Linux tests pre-created the protected host paths. A missing protected path still causes exit 78.
- Container checks do not qualify every Linux host or namespace policy.
- Interactive GUI operation and live worker inheritance remain unverified.
- Scripts that parse CLI help layout, colours or suggestion text must use the new presentation contract.
- Asset replacement is local build preparation. It is not an atomic transaction across multiple files or an automatic publication step.
