# Recover failed automatic Codex initialization

## Outcome

The protected installer recovers through local stdio when an automatically discovered Codex socket fails initialization.
Explicit socket failures remain failures. An operation that reached the server is never retried.

## Change classes

The RPC client records whether socket discovery was automatic.
An internal error tag identifies initialization failure before the requested operation is sent.
Existing exception classes, review policy, isolation and native server ownership remain unchanged.

## Evidence

The local shared socket fails initialization with both installed CLI versions. Local stdio works.
Regression cases reproduce timeout and RPC rejection before initialization.
They now recover. Negative controls preserve explicit socket failure and prevent a second configuration write after an operation timeout.

## Residual risk
