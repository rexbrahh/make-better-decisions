# v1.2.1

## Outcome

Review no longer requests required contracts that the hook read and then discarded to meet its evidence budget. Complete quoted heredocs for diagnostic programs can mention `ts-decide` as data without triggering consultation enforcement.

## Change classes

- Retain the path, full-content SHA, trust label, and baseline metadata for required source files. Shorten excerpts and remove optional observations to meet the existing evidence budget.
- Preserve required records when the hook adds source freshness and architecture metadata.
- Separate heredoc data from executable shell input. Detect consultations after newlines and common literal execution wrappers. Preserve ordinary command lookups and data arguments.
- Report an unintercepted invocation without claiming that the hook is inactive. Preserve exit 3 and the unverified result.
- Add regression tests. Resolve temporary test paths so macOS source-race fixtures match the canonical reader paths.

## Verification

The new regressions failed before the corrections. Current-source replays reproduce two peer failures. Field Store previously retained four of six required files. Hosted previously retained five of eight required files, omitting the error header and both web contracts. The corrections retain every required file with its full-content SHA, including after freshness metadata is added, within the 80,000-character evidence budget.

All 370 tests pass under macOS system Python 3.9.6 and Homebrew Python 3.15. Independent review found the wrapper cases and verified that unsupported invocation forms cannot supply decision authority. The diff passes the whitespace check.

See the [validation record](../validation/contract-budget-2026-10-13.md) for the final checks and limits.

## Residual risk

Source excerpts can be shorter than the source file. Existing file-size, scan, redaction, and private-path limits still apply. These replays verify evidence construction; they do not approve a peer design or prove that Jev will accept it. Nested shell programs and dynamic substitutions remain outside the standalone consultation format. Unintercepted calls exit 3 and cannot supply decision authority. Native MCP peer tools remain absent in the observed CLI runtimes. A Hosted status report arrived through the native Codex queue.
