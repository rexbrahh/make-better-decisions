# Fix evidence slicing and oracle races

Evidence clipping now uses byte offsets when every decoded code point occupies one byte.
The original 1.5-second evidence-build test passes under the race detector without a larger timeout.
Unicode, surrogate and invalid-byte slicing retain their existing results.

Jev captures each request's endpoint and transport before its background work starts.
The gate oracle synchronizes access to its recorded request bodies.

Unit suite, frozen Jev oracle, live Jev gates, vet and diff checks pass.
The oracle permits only the additive provider-option help text. Both release assets match their SHA-256 pins.
The complete race suite also passes with the frozen oracle enabled.

Jev remains the default. Snap remains opt-in with its existing authority policy and provider isolation.
