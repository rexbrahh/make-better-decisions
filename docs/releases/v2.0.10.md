# Discover scoped Claude plugin entries

## Outcome

Claude plugin discovery reads scoped registry arrays and legacy object entries.
Repeated paths shared by user and project scopes appear once.

## Change classes

Discovery iterates registry entries through the existing path, disabled-entry and file checks.
It sorts and compacts the resulting manifest paths.
Native server ownership, manifest expansion and recipe validation remain unchanged.

## Evidence

The regression misses its scoped manifest before the fix.
Afterward it returns both expected manifests once and skips disabled and malformed entries.
The complete installer package and its Python oracle pass.
The live selected registry contains 36 scoped arrays; the next release corrects selected-root lookup.

## Verification

Unit suite, complete Python oracle, live Jev gates, vet and diff checks pass.
Both release assets match their SHA-256 pins.
