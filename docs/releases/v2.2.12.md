# Redact containing credentials first (v2.2.12)

When one known credential contained another, replacement order could leave part of the longer credential visible.
The shared redactors now replace longer credentials first and preserve caller-owned lists.
This covers review inputs, returned metrics and credential-bearing record identifiers for Jev and Snap.

The credential threshold, pattern checks, marker collision protection and review policy remain unchanged.
Jev remains the default and Snap remains opt-in.

Regression tests fail before repair and pass afterward.
All 26 product packages pass on Mac with race detection and frozen CPython comparisons, and on Linux amd64.
Both release assets build twice identically. Independent source review finds no confirmed defect in the selected repair.
