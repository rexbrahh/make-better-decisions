# v1.2.0

## Outcome

Decision review supplements the host instead of controlling every tool. Ordinary commands, peer messages, worker dispatch, questions, unknown tools, and completion continue without Jev. Declared edit/patch tools, filesystem write/edit APIs, plan acceptance, and explicit consultations retain review.

## Change classes

- Replace catch-all tool classification with a small sensitive surface. Preserve the local private-state guard and host controls.
- Remove automatic Stop/SubagentStop registration. Previously loaded completion callbacks return without review or blocking.
- Add owner-signed canonical-session exceptions. Honor them after native identity validation and the private guard, including native workers. Preserve them across upgrades until explicit revocation.
- Add regressions for zero-API ordinary execution, missing context, identity mismatch, tampered policy, and revocation. Update both manifests and current contracts.

## Verification

The new ordinary-call and completion tests failed before the dispatcher correction. The owner-exception tests failed before implementation. All 363 tests passed under system Python and Homebrew Python, including native sandbox checks. Independent review identified and resolved cross-host exception scope and stale contract text. Ordinary-call tests verify zero API requests and no context construction. Exception tests verify that an owner waiver overrides a semantic denial without generating a decision receipt.

## Residual risk

Automatic decision enforcement covers the declared sensitive surface. Other interfaces follow host permissions and agent instructions. Explicit session exceptions persist until owner revocation. Native peer messaging from the owner chat, native Claude activation, and Linux bubblewrap runtime remain unverified.
