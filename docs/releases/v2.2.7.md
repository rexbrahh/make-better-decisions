# Assign scoped receipts to encrypted native workers

Native Codex workers can inherit a scoped review when Codex hides their task brief.
The parent sets `task_name` to `ad_` followed by the completed receipt ID.
The fallback assigns only the receipt's picked option through the matching completed dispatch.

Native ancestry, shared session, repository, review identity, scope, source freshness and coverage checks remain required.
Readable Codex briefs and Claude dispatches retain their existing assignment and advisory-override rules.
Jev remains the default with required review. Snap remains opt-in.

See the [validation record](../validation/native-worker-inheritance-2026-10-16.md) for regression, native and installation evidence.
