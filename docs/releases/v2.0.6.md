# Reject inconsistent release versions

## Outcome

Release builds stop before invoking Go when the Claude and Codex manifest versions are missing or different.
Previous assets and SHA-256 pins remain intact.

## Change classes

The build script reads both manifest versions with its existing extraction method.
It checks their equality before toolchain detection and staging.
The shared test fixture now includes both manifests.

## Evidence

Mismatch and missing-version fixtures incorrectly succeed before the fix.
After the fix, both fail before invoking the fake Go executable and preserve all previous assets and pins.
The matching-version control and second-target build-failure check pass.
A real isolated two-target build reproduces the archived release pins exactly.

## Verification

Unit suite, complete Python oracle, live Jev gates, vet and diff checks pass.
Both release assets match their SHA-256 pins.

## Upgrade

Update both native plugins and run their protected installers. Trust the changed Codex hooks.

## Residual risk

Version extraction retains the existing manifest formatting contract.
GUI operation and live worker inheritance remain unverified.
