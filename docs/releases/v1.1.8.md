# v1.1.8

## Outcome

Plugin cache removal no longer removes installed decision runtime entrypoints. Codex and Adrafinil retain their native launchers. Required hook review remains active.

## Change classes

- Publish verified runtime bundles outside the plugin cache. Atomically activate `current` and retain older bundles.
- Preserve native registrations and restore legacy wrappers from signed transport recipes. Keep third-party stdio isolation and host permission defaults.
- Protect the runtime namespace, pointer, and bundles. Hooks select the protected runtime after installation and report failure when that runtime is broken.
- Add cache-removal, interrupted-update, source-change, source-symlink, migration, and native sandbox protection tests. Update installation procedures and both manifests.

## Verification

The full suite passed 354 tests under both system Python and Homebrew Python. Targeted tests executed a hook and a signed stdio launcher after deleting their source cache. Native macOS sandbox tests denied runtime pointer replacement and bundle writes. Independent review found no actionable issues. Native desktop read-only peer status succeeded after launcher repair and restart.

## Residual risk

The owner must run the boundary helper after a plugin upgrade to publish the new runtime. Earlier loaded hook registrations require a host reload during this one-time migration. Linux bubblewrap runtime and native Claude activation remain unverified. Retained runtime bundles require owner-managed cleanup when no running processes use them.
