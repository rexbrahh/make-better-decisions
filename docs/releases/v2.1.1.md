# Redact installer timeout diagnostics

Installer timeout errors now sanitize child stderr before they print it.
The existing sanitizer removes supported token flags and URL credentials before the 500-character limit applies.
If malformed input prevents sanitization, the diagnostic becomes `<redacted>`.
The error still identifies the RPC method and timeout.

Six direct cases cover ordinary text, Unicode clipping, credential forms, long values and malformed URLs.
Two child-process cases cover response timeouts and blocked request writes.
