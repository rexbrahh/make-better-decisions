# Preserve Codex question answers and their history order (v2.2.14)

Codex can return a question answer with only the first 512 UTF-8 bytes of the displayed title.
The plugin now accepts that echo for a completed asynchronous question when its tool, call ID and item index match.
The echo must be an exact prefix and valid UTF-8. Only the answer supplies user authority.

When an upgrade recovers a previously omitted answer, the plugin preserves its position before later user instructions.
It first checks that the current native records reproduce the signed human words in their existing order.
If that history is incomplete, it retains the signed words and leaves the answer unverified until complete context returns.

Both release assets build twice identically with Go 1.27.2.
See the [validation record](../validation/v2.2.14-qa-2026-10-19.md) for the checks and their limits.
The provider chooser, Jev default, review policy and session exceptions remain unchanged.
