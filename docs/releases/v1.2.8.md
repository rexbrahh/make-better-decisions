# v1.2.8

## Outcome

Each hook call starts about 33 ms faster. In a published bundle, the hook import takes a median of 51 ms. The v1.2.7 bundle took 84 ms. Every hook event pays this cost, and so do the Python routes that remain after the Go router of the next release.

## Change classes

- `runtime.publish` compiles each module in the stage directory to checked-hash bytecode before it activates the bundle. The hooks run `python3 -B`, which reads bytecode but does not write it. Before this release, every call compiled the bundle again.
- A Python that sets `sys.pycache_prefix` does not compile. Apple's `/usr/bin/python3` keeps bytecode under `~/Library/Caches/com.apple.python`, so it would write outside the bundle and not read the bundle bytecode.
- `jev.py` imports `urllib.request` only when it sends a request to Jev. Hook calls that do not ask Jev no longer pay this import.

## Evidence

- Measured on 2026-10-14 with Homebrew Python 3.15, median of 40 runs. Python startup took 18.0 ms. The v1.2.7 hook import took 84.6 ms, and 62.7 ms with bytecode. With bytecode and the lazy urllib import, it took 44.9 ms (unchecked hash) or 47.3 ms (checked hash).
- `python3 -X importtime` showed `agent_decisions.jev` at 20.8 ms cumulative, including 11.9 ms for `urllib.request`. In the v1.2.8 bundle, `agent_decisions.hook` takes 27.0 ms cumulative. It was 48.4 ms before.
- Checked-hash bytecode costs about 2.4 ms more per call than unchecked hash. Python reads and hashes the source file at import, so a changed source file never runs stale bytecode. Jev picked checked hash (ADVISORY, `review_0405500e`).
- The owner chose "v1.2.8 first, then S1 (Recommended)". Jev picked this release before the Go router (ADVISORY, `review_0f1d1284`).
- A traceback from bundle bytecode names the source file under `current`, not the stage directory. Python corrects the code file name when it loads bytecode.

## Verification

Two new tests cover this release. The first checks that each bundle module has checked-hash bytecode. Apple Python 3.9.6 skips it because it sets `pycache_prefix`. The second checks that an import of `agent_decisions.hook` from a bundle does not load `urllib.request`. All 388 tests pass under Homebrew Python 3.15. 387 pass and one is skipped under macOS system Python 3.9.6. Both runs were outside the Claude Code Seatbelt sandbox.

A bundle published to a scratch home imported in 51.0 ms. The live v1.2.7 bundle took 83.6 ms on the same machine.

## Residual risk

- The bytecode matches only the Python that publishes the bundle. A hook that runs a different `python3` compiles at import, as all versions did before. Run the installer with the `python3` that the hooks use. The native hooks on this machine use Homebrew Python. An install under Apple's `/usr/bin/python3` publishes no bytecode.
- Activation changes the checks of every running agent at its next tool call.
