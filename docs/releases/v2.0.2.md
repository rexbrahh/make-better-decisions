# Preserve Claude settings aliases

## Outcome

The installer updates the resolved settings target and preserves its symlink.
This also works when the symlink target does not exist yet.

## Change classes

`WriteJSON` uses the existing canonical-path helper before its atomic private-file replacement.
Argument handling, hook responses, review policy and ledger encoding remain unchanged.

## Evidence

Both new regression cases fail on v2.0.1 because the installer replaces the alias with a regular file.
Both pass after the correction. The target receives the expected settings with mode `0600`.

## Verification

Unit suite, complete Python oracle, live Jev gates, vet and diff checks pass.
Both release assets match their SHA-256 pins.

## Upgrade

Update the native plugin and run its protected installer for each host.
Trust the changed Codex hooks. The local campaign updates both existing Claude scopes.

## Residual risk

Native GUI operation and live worker inheritance remain unverified.
The Linux missing-protected-path policy remains unchanged.
