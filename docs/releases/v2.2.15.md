# Identify Snap transport failure phases (v2.2.15)

Future Snap failure metrics identify whether `http.Client.Do` or the response-body read returned the error.
The fixed tags are `request` and `response_body`.
Public error text, failure categories and review outcomes retain their existing behavior.

Admission, HTTP status, size and validation failures receive no transport phase.
The tags identify the call site of the returned failure. They do not establish a backend cause or historical service recovery.

Linux passes 962, and eight native macOS confinement checks pass.
