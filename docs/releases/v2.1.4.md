# Keep Claude plugin command matchers

Claude installation plans now retain each plugin's command matcher when server names collide.
Previously, the last recipe under a short name hid earlier commands from shell-prefix isolation.
Claude gives plugin servers separate names, so those commands can coexist.
See [Claude's plugin server documentation](https://code.claude.com/docs/en/mcp#plugin-provided-mcp-servers).

The repair reuses the current parsers and native-launcher checks.
It appends missing matchers while preserving existing recipe names and matcher order.
Identical command and argument lists add no duplicate matcher.
Owner configuration precedence, validation, protected paths and decision review remain unchanged.

The collision regression fails before the repair and passes afterward.
